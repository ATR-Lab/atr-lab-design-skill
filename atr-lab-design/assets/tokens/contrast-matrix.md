# ATR Lab contrast matrix

Computed WCAG 2.x contrast ratios (relative luminance, sRGB). Generated by `src/build_tokens.py`; do not edit by hand.

Thresholds (WCAG 2.2 AA):

| Use | Minimum | Criterion |
|---|---|---|
| Normal text (< 24 px regular, < 18.66 px bold; < 18 pt / 14 pt bold) | **4.5:1** | 1.4.3 |
| Large text (>= 24 px regular or >= 18.66 px bold; >= 18 pt / 14 pt bold) | **3:1** | 1.4.3 |
| Non-text: icons, chart marks, input borders, focus rings | **3:1** | 1.4.11 |

Legend: **AAA** >= 7, **AA** >= 4.5 (any text), **Large/UI** >= 3 (large text and non-text only), **Fail** < 3 (decorative only).

## Data-viz marks by surface: why the plot area sits on the chart surface
