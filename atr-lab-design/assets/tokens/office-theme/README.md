# ATR Lab Office theme (PowerPoint, Word, Excel)

One theme named **ATR Lab** carries the lab's colors and fonts into Microsoft Office. Apply it once and the theme color picker, chart series, SmartArt, tables and the default fonts all follow the brand.

| File | What it is | Use it for |
|---|---|---|
| `ATR-Lab.thmx` | Complete Office theme package (colors + fonts + effects + custom colors + thumbnail) | Apply to any deck or document, or install so it appears in the Themes gallery |
| `theme1.xml` | The theme part itself (`a:theme name="ATR Lab"`) | Template builders: drop in as `ppt/theme/theme1.xml` (PowerPoint) or `word/theme/theme1.xml` (Word) |
| `ATR-Lab-colors.xml` | Theme Colors file (`a:clrScheme name="ATR Lab"`) | Install as a custom color set (Design > Variants > Colors) |
| `ATR-Lab-fonts.xml` | Theme Fonts file (`a:fontScheme name="ATR Lab"`) | Install as a custom font set (Design > Variants > Fonts) |

All four are generated by `../src/build_tokens.py`. Do not hand-edit them; change `../src/palette_def.py` and rebuild.

## Color slots

| Slot | Hex | Token | Notes |
|---|---|---|---|
| Text/Background - Dark 1 (`dk1`) | `#1B2533` | ink | Default text color. 15.5:1 on white. |
| Text/Background - Light 1 (`lt1`) | `#FFFFFF` | white | Default background. |
| Text/Background - Dark 2 (`dk2`) | `#003976` | navy | Title color and navy fields. |
| Text/Background - Light 2 (`lt2`) | `#F3F6FA` | mist | Panels, alternate rows. Cool, never cream. |
| Accent 1 | `#003976` | data-1, ATR Navy | Chart series 1, default shape fill. |
| Accent 2 | `#EFAB00` | data-2, ATR Gold | Chart series 2. Fills only: never white text on it. |
| Accent 3 | `#2C8ECD` | data-3, Sky | Chart series 3. |
| Accent 4 | `#B63B35` | data-4, Brick | Chart series 4. |
| Accent 5 | `#059583` | data-5, Teal | Chart series 5. |
| Accent 6 | `#DC7533` | data-6, Orange | Chart series 6. |
| Hyperlink (`hlink`) | `#1D65B9` | navy-600 | 5.8:1 on white. |
| Followed hyperlink (`folHlink`) | `#663E9E` | link.visited | 7.6:1 on white. |

Accents 1-6 are exactly the first six slots of the validated ATR categorical data palette, in order, so a native PowerPoint or Excel chart gets the right series colors without any recoloring. Slots 7-8 of the data palette (Plum `#7D4DAD`, Field Green `#47A34E`) are not theme slots; if a chart truly needs them, set them by hex.

The theme also carries a **custom colors** list (`a:custClrLst`): ATR Navy, ATR Gold, Midnight, Sky, Ink, Slate, Bronze, Mist, Line, Flash. PowerPoint shows these as a "Custom Colors" row in the color picker where the app version supports theme custom colors.

## Fonts

Heading (major) and body (minor) Latin fonts are both **Source Sans 3**. Headings get their weight from the templates (Bold or the "Source Sans 3 Black" family), not from the theme. East Asian and complex-script slots keep Office's defaults. Install the fonts from `../../fonts/` first (see its README), and embed them when a file leaves your computer.

## Apply or install the theme

**Apply to one file**
- PowerPoint (Windows or Mac): **Design** tab > Themes gallery **More** arrow > **Browse for Themes...** > pick `ATR-Lab.thmx`.
- Word: **Design** > **Themes** > **Browse for Themes...** > pick `ATR-Lab.thmx`.
- Excel: **Page Layout** > **Themes** > **Browse for Themes...**

**Install so it appears in every gallery**
- Windows: copy `ATR-Lab.thmx` to `%APPDATA%\Microsoft\Templates\Document Themes\`, `ATR-Lab-colors.xml` to `...\Document Themes\Theme Colors\` and `ATR-Lab-fonts.xml` to `...\Document Themes\Theme Fonts\`.
- macOS: copy `ATR-Lab.thmx` to `~/Library/Group Containers/UBF8T346G9.Office/User Content/Themes/` (Finder may show the folders as `User Content.localized/Themes.localized`), and the two XML files into its `Theme Colors` and `Theme Fonts` subfolders.
- Restart Office. The theme appears under **Custom** in the Themes gallery; the colors and fonts appear at the top of **Design > Variants > Colors / Fonts**.

The ATR PowerPoint and quad-chart templates already contain this theme; you only need the `.thmx` for decks and documents started elsewhere.

## Things to avoid

- **Table, SmartArt and shape styles built on Accent 2 (gold)** set white text on gold (2.0:1), which fails. Use Accent 1 (navy) styles, or recolor the text to navy/ink.
- **Hyperlinks on navy slides** keep the theme link color (navy-600), which disappears on navy. Recolor those links to navy-200 `#BCD7F8` and keep them underlined.
- **Gold chart lines on white** (series 2 as a thin line) are 2.0:1. Thicken to 2.25 pt or more and add data labels or a direct series label.
- Do not "Reset" a slide to a non-ATR theme, and do not paste slides with **Keep Source Formatting** from other decks; use **Use Destination Theme**.

## Exact XML (for template builders)

`ATR-Lab-colors.xml` / the `a:clrScheme` inside `theme1.xml`:

```xml
<a:clrScheme name="ATR Lab">
  <a:dk1><a:srgbClr val="1B2533"/></a:dk1>
  <a:lt1><a:srgbClr val="FFFFFF"/></a:lt1>
  <a:dk2><a:srgbClr val="003976"/></a:dk2>
  <a:lt2><a:srgbClr val="F3F6FA"/></a:lt2>
  <a:accent1><a:srgbClr val="003976"/></a:accent1>
  <a:accent2><a:srgbClr val="EFAB00"/></a:accent2>
  <a:accent3><a:srgbClr val="2C8ECD"/></a:accent3>
  <a:accent4><a:srgbClr val="B63B35"/></a:accent4>
  <a:accent5><a:srgbClr val="059583"/></a:accent5>
  <a:accent6><a:srgbClr val="DC7533"/></a:accent6>
  <a:hlink><a:srgbClr val="1D65B9"/></a:hlink>
  <a:folHlink><a:srgbClr val="663E9E"/></a:folHlink>
</a:clrScheme>
```

Font scheme: `<a:fontScheme name="ATR Lab">` with `<a:latin typeface="Source Sans 3" panose="020B0503030403020204"/>` in both `a:majorFont` and `a:minorFont` (see `ATR-Lab-fonts.xml` for the full script list).

In python-pptx, the simplest route is to replace the `ppt/theme/theme1.xml` part of a saved deck with `theme1.xml` (zip in, zip out); in pptxgenjs, set colors by hex from `../colors.json` and post-process the theme part the same way.

## How it was checked

- `theme1.xml` validates against the ECMA-376 DrawingML schema (`dml-main.xsd`) shipped with the Anthropic pptx skill.
- The part was injected into a test deck that passed the pptx skill's `validate.py` and rendered in LibreOffice with Source Sans 3 as the body font, accents 1-6 as the six series of a native clustered-column chart in order, and the hyperlink in navy-600 (`build/qa/tokens/theme_test-page-1.png`).
- The `.thmx` package follows the structure Office writes (`[Content_Types].xml`, `_rels/.rels`, `theme/theme/themeManager.xml` + its rels, `theme/theme/theme1.xml`, `docProps/thumbnail.jpeg`); every part is well-formed. Desktop PowerPoint was not available on the build machine, so apply the `.thmx` once in PowerPoint to confirm before rolling it out to the lab.
