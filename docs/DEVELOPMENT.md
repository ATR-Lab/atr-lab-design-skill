## Regenerate templates and assets

Every shipped template and image is generated by a script: in `build/`, or for the icons and tokens, in the skill
itself. The template generators validate, measure and render their own output and stop on the first failure. Do
not hand-edit generated files; change the generator and rerun it.

**Before you run anything, adjust the machine paths.** The build scripts hard-code the paths of the machine they
were built on:

- `ROOT`, the repository path
- `SCRATCH`, a scratch folder holding the Python venv at `$SCRATCH/venv` and the Node modules at `$SCRATCH/node/node_modules`
- the location of the Anthropic pptx skill's `validate.py`
- in `build/tools/render.sh`, a font folder

Point them at your machine. For fonts, use `atr-lab-design/assets/fonts/`, or render with the skill's own
`atr-lab-design/scripts/render_office.sh`.

**Toolchain:**

- **Node:** `pptxgenjs` 4.0.1, `sharp` and `docx` 9
- **Python:** python-pptx, Pillow, numpy, lxml, defusedxml, fonttools and segno (for poster QR codes)
- **Other:** LibreOffice, poppler and `rsvg-convert`. The Codex CLI is needed only to regenerate AI imagery.

| What | Command (from the repository root unless noted) | Writes |
|---|---|---|
| Presentation template | `build/templates-src/presentation/run.sh` (`--skip-art` keeps the seeded constellation art) | `ATR-Presentation-Template.pptx`, `.potx` and `presentation-layouts.json` in `atr-lab-design/assets/templates/` |
| Quad chart template | `build/templates-src/quad/run.sh` | `ATR-Quad-Chart-Template.pptx`, `quad-layouts.json` |
| Research posters | `bash build/templates-src/poster/build.sh`, then `cp build/templates-src/poster/gen/poster-layouts.json atr-lab-design/assets/templates/` | `ATR-Research-Poster-48x36.pptx`, `-36x48.pptx`, `poster-layouts.json` |
| Print set and email signature | `build/templates-src/print/build.sh all` (one piece: `flyer`, `certificate`, `one-pager`, `badge`, `door-sign`, `letterhead`, `signature`; bleed versions: `all --bleed`) | the Letter templates, badge, letterhead `.docx` and `email-signature.html` / `.txt` |
| Social templates | `build/templates-src/social-pptx/build.sh` | `atr-lab-design/assets/templates/social/*.pptx` |
| Logo library | `build/logos-src/run_all.sh` (`--retrace` redoes the potrace tracing) | `atr-lab-design/assets/logos/` and its README and `logos.json` |
| Icons | the skill's own pipeline, `atr-lab-design/scripts/icons/` (see its README), with the selection and prompts recorded in `build/icons-src/` | `atr-lab-design/assets/icons/` |
| Patterns, backgrounds, illustrations, banners | in `build/illustrations-src/`: `patterns.py`, `generate.py` (Codex), `finish.py`, `poster_band.py`, `composites.py`, `make_readme.py` | `atr-lab-design/assets/patterns/`, `atr-lab-design/assets/illustrations/` |
| Design tokens | `atr-lab-design/assets/tokens/src/build_tokens.py`, `build_swatch_card.py`, `check_tokens.py`, `render_samples.py` | `atr-lab-design/assets/tokens/` |

After any rebuild:

1. Lint the templates with `atr-lab-design/scripts/brand_check.py atr-lab-design/assets/templates/ --template`. Today every template reports 0 errors and 0 warnings.
2. Look at the contact sheets in `build/qa/`.
3. Remove strays: `find atr-lab-design \( -name __pycache__ -o -name .DS_Store \) -prune -exec rm -rf {} +`.
